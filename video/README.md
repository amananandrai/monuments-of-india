# Monuments of India: the video

A tour of all 101 monuments from the website, five seconds each (8 min 25 s, 1920×1080 at 30 fps),
made with [HyperFrames](https://hyperframes.heygen.com): HTML rendered to MP4 frame by frame.

Each monument is drawn with the site's own 3D models, sky, land and water while the camera sweeps
slowly round it, under a title card with its name in English and in its local script, the place,
and one line of facts. The film dips to black between monuments. It is silent.

## Render it

Needs Node.js 22+ and FFmpeg.

```bash
cd video
npm install
npm run render
```

`npm run render` first runs `npm run sync`, which copies the site's models (`../js`) and textures
(`../assets/textures`) into this folder, with three.js, GSAP and the title fonts, and regenerates the
title cards and the root `index.html` from `../js/data.js`. The film lands in
`renders/monuments-of-india.mp4`. On a machine without a GPU, Chrome draws the 3D on the CPU and a
full render takes about four hours; with a GPU it is much faster.

`npm run dev` opens the HyperFrames preview to scrub through it; `npm run check` lints and audits it.

## Files

- `compositions/tour.html`, `tour.js`: the 3D tour, drawn from timeline time.
- `compositions/titles-01.html` … `titles-11.html`: the title cards, ten monuments per file.
- `compositions/dips.html`: the dips to black.
- `index.html`: mounts the tour, the titles and the dips.
- `sync-site.mjs`: the sync step. `index.html`, the title files and `dips.html` are generated by it,
  so change `../js/data.js` or the generator rather than those files.
